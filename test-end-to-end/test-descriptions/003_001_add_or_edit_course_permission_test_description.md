# Admin or teacher can edit the course

## Description:

Admin or teacher can edit the course details. Other users do not have permission to edit the course.

## Step-by-Step Procedure:

1. Using http api endpoint created a class with students and teachers already enrolled and setup.
2. Login as admin.
3. Click on "Courses."
4. Click on the course name.
5. Verify that the edit button is visible for the admin user.
6. Click on the edit button.
7. Verify that the admin has the edit permission.
8. Clear the app storage.
9. Log in as the teacher.
10. Click on "Courses."
11. Click on the course name.
12. Verify that the edit button is visible for the teacher user.
13. Click on the edit button.
14. Verify that the teacher has the edit permission.
15. Click on "Save" button.
16. Clear the app storage.
17. Log in as the student.
18. Click on "Courses."
19. Verify that the edit button is not visible for the student user.
