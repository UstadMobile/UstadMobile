# Users on same course can send a chat message

## Description:

Users can send a chat message (plain text) to any other user that they have permission to see (teachers and students can see those who are part of their courses by default). The recipient can reply to the message. Messages/replies are delivered instantly when the app is open. Note: Messages are only delivered if the app is open and notifications are not displayed.

## Step-by-Step Procedure:

1. Using http api endpoint created a class with students and teachers already enrolled and setup.
2. Login to the app using the teacher username and password. 
3. Click on "Messages" tab at bottom 
4. Click on "+ Message" button 
5. Select a student from student list. 
6. Enter message in "Message" tab 
7. Click on "Send" icon. 
8. Verify the message is visible. 
9. Clear the app storage 
10. Login to the app using the student username and password.
11. Click on "Messages" tab at bottom
12. Verify student able to see message from teacher
13. Click on teacher name to open the message
14. Verify user able to see the message from teacher with date and time.
15. Enter message in "Message" tab to reply 
16. Click on "Send" icon.
17. Clear the app storage 
18. Login to the app using the teacher username and password. 
19. Click on "Messages" tab at bottom 
20. Verify teacher able to see reply message from the student.
