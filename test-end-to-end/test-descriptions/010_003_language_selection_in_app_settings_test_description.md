# Language Selection in App Settings

## Description:

After login, user can go to settings, and select any supported language, or to use the system device language. The user interface will change to the selected language. The language setting is applied to the whole app, not per-user (if a user switched accounts, the language does not change - language setting is stored locally).

## Step-by-Step Procedure:

1. Launch the Ustad app.
2. Click on "Existing User" button
3. Click on "Enter link manually" button
4. Enter the site link
5. Login as admin
6. Verify user able to see settings icon at the top
7. Click on "Settings"
8. In the Settings menu, find the App Language option. 
9. Click on the Language option to open the language selection menu. 
10. In the language selection menu, choose any supported language from the list. 
11. The app gets restated automatically or else ask permission to close the app
12. Click on "Close now" if user gets pop-up asking to close the app.
13. Open the app
14. Observe that the app’s user interface immediately changes to reflect the selected language.
15. Navigate through different sections of the app (e.g., "Courses," "People," "Settings"). 
16. Ensure all menus, instructions, and buttons are displayed in the newly selected language.
17. Click on "People"
18. Click on "+ Person" button.
19. Enter new user details like firstname, lastname and gender
20. Click on "Save" button.
21. Click on " Create account" button.
22. Enter username and password.
23. Click on "Save" button. 
24. Admin user clicks on "Accounts" icon
25. Click on "Log out" button. 
26. Close the app
27. Log in using a different account. 
28. Confirm that the app’s language remains the same as previously set, demonstrating that the language setting is stored locally and not tied to individual user accounts.
