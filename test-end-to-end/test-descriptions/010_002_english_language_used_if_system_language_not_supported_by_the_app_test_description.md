# Default English language is used on app if the language is not supported by the app

## Description:

If the system is set to an unsupported language, the app will be displayed in English (fallback language).

## Step-by-Step Procedure:

1. On the user’s device, navigate to system settings.
2. Set the device language to **Malayalam**.
3. Launch the Ustad app.
4. Launch Ustad app
5. Click on "Existing User" button
6. Click on "Enter link manually" button
7. Enter the site link
8. Observe the language used during the app's initial load.
9. Verify that the app's instructions are displayed in **English**.
10. On the app’s login screen, enter the admin username and password.
11. Click the login button.
12. Confirm that all login-related instructions and buttons are displayed in **English**.
13. Navigate through various sections of the app (e.g., "Courses," "People," "Library").
14. Verify that all features, functions, and instructions are in **English**.
