# User can store offline content on device storage or memory card 

## Description:

User can select (in settings) to store content on device storage or memory card (if available - Android apps can only use storage on memory cards that are reformatted on the device to use as storage (not FAT32 etc)). Any subsequent download is saved on the selected storage medium. (Android only).

## Step-by-Step Procedure:

1. Go to File-Downloads and make sure content file is there in downloads for test
2. Launch Ustad app 
3. Click on "Existing User" button  
4. Click on "Enter link manually" button  
5. Enter the site link  
6. Login as admin.
7. Click on "Settings."
8. Click on the "Offline items storage" button.
9. Click on the "Memory card" option. 
10. Click on "Library."
11. Click on the "+ Content" button. 
12. Click on the "From file" button. 
13. Select the H5p content file. 
14. Click the "Save" button. 
15. Verify that the content is visible in the library.
16. Close the app.
17. Open file manager app to check the storage location and confirm the file is in the appropriate directory.
