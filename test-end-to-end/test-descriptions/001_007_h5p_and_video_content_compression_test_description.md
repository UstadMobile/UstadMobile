# H5P and Video Content Compression

## Description:

H5P and video content can be automatically compressed using high, medium, and low quality presets.

## Step-by-Step Procedure:

1. Go to File-Downloads and make sure content file is there in downloads for test
2. Launch Ustad app  
3. Click on "Existing User" button  
4. Click on "Enter link manually" button  
5. Enter the site link  
6. Login as admin.
7. Click on "Library."
8. Click on the "+ Content" button.
9. Click on the "From file" button.
10. Select the content file.
11. Click the "Save" button.
12. Verify that the content is visible in the library.
13. Click on the content.
14. Wait for the importing and uploading to complete. 
15. The size should reflect the applied compression settings (high, medium, low). 
16. In brackets, the original file size should be shown for comparison. 
17. Ensure that the compressed file size is smaller than the original file size.
