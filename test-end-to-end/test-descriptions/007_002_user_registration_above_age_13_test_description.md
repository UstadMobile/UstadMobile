# When registration is enabled: Users over 13 can register directly

## Description:

When registration is enabled: Users over 13 can register directly

## Step-by-Step Procedure:

1. Login as admin.
2. Click on "Settings" icon.
3. Click on "Site" button.
4. Click on "Edit" button.
5. Enter Company terms in "Terms and policies" text field.
6. Click on "Registration allowed" switch.
7. Click on "Save" button
8. Clear app storage.
9. Click on "Create account" button.
10. Click on the "Next" button.
11. Verify user gets an error "This field is required."
12. Select date of birth , age 13+
13. Read company terms and policies.
14. Click on "Accept" button.
15. Enter First name
16. Enter Last name
17. Select Gender.
18. Select country code
19. Enter Phone number.
20. Enter email id.
21. Enter Address.
22. Enter username.
23. Click on "Register" button.
24. Verify the user gets error "This field is required" just below the "Password" field.
25. Clear the username field.
26. Enter the password field.
27. Click on "Register" button.
28. Verify the user gets error "This field is required" just below the "Username" field.
29. Enter the Username.
30. Leave the Firstname field as blank.
31. Click on "Register" button.
32. Verify the user gets error "This field is required" just below the "First name" field.
33. Leave the Last name field as blank.
34. Enter the First name.
35. Click on "Register" button.
36. Verify the user gets error "This field is required" just below the "Last name" field.
37. Leave the Gender field as blank.
38. Enter the last name.
39. Click on "Register" button.
40. Verify the user gets error "This field is required" just below the "Gender" field.
41. Select the "Gender" field.
42. Enter invalid email id without "@" symbol in email id field.
43. Click on "Register" button.
44. Verify user gets an error just below email id as "Invalid"
45. Clear the email id field.
46. Enter invalid email id with a white space in email id field.
47. Click on "Register" button.
48. Verify user gets an error just below email id as "Invalid".
49. Clear the email id field.
50. Enter valid email id in the email id field.
51. Enter invalid phone number with 5 digits in Phone number field.
52. Click on "Register" button.
53. Verify user gets an error just below phone number as "Invalid"
54. Clear the phone number field.
55. Enter valid phone number in the phone number field.
56. Click on "Register" button.
57. Verify that user is logged into the app.
