# Admin or teacher send invitation via message using username

## Description:

Teacher (course leader) or admin can send an invitation to a list of users by providing student username. User can open the invitation, create a new account if this is allowed by admin policy, and join a course.

## Step-by-Step Procedure:

1. Launch Ustad app
2. Click on "Existing user" button
3. Click on "Learning Space" button
4. Click on "Enter link manually" button
5. Enter the link in "Site link" field
6. Click on "Next" button
7. Login as admin.
8. Click on "Courses.
9. Click on the course name.
10. Click on the "Members" tab.
11. Click on the "Invite Students" button.
12. Enter student usernames starting with symbol "@" separated by commas (eg: @stud1,@stud2).
13. Click "Send."
14. Go to messages
15. Verify the messages are invites are sent to students
16. Clear the app storage
17. Launch Ustad app 
18. Click on "Existing user" button
19. Click on "Learning Space" button
20. Click on "Enter link manually" button
21. Enter the link in "Site link" field
22. Click on "Next" button
23. Login as student.
24. User gets an invitation page that prompts the user to join the course.
25. The student clicks "Accept."
26. Verify that the student appears in the course members list.
27. Clear storage
28. Login as a teacher
29. Go to courses
30. Open the course and verify the student is enrolled to the course.
