# When registration is enabled: Users under 13 can register using parental approval link

## Description:

When registration is enabled: Users under 13 can register using parental approval link

## Step-by-Step Procedure:

1. Login as admin.
2. Click on "Settings" icon.
3. Click on "Site" button.
4. Click on "Edit" button.
5. Enter Company terms in "Terms and policies" text field.
6. Click on "Registration allowed" switch.
7. Click on "Save" button
8. Clear app storage.
9. Click on "Create account" button.
10. Click on the "Next" button.
11. Verify user gets an error "This field is required."
12. Select date of birth , age less than 13
13. Enter First name
14. Enter Last name
15. Select Gender.
16. Enter Parents' email address.
17. Enter username.
18. Enter password.
19. Click on "Register" button.
20. User directed to Login page.
21. Student user enter username and password
22. Click "Login" button
23. User gets error saying need parental consent for login
24. Parent user check the Parental email given during registration.
25. Click on the link on email received
26. Parent directed to login page.
27. Parent click on "Create account" button.
28. Select date of birth , age 13+
29. Read company terms and policies.
30. Click on "Accept" button.
31. Enter First name
32. Enter Last name
33. Select Gender.
34. Select country code
35. Enter Phone number.
36. Enter email id.
37. Enter Address.
38. Enter username.
39. Enter password.
40. Click on "Register" button.
41. Verify that user is parental consent page.
42. User clicks on "Approve" button.
43. Clear the app storage.
44. Login using student username and password to the app.
45. Verify the student user is able to login and view the app features.
