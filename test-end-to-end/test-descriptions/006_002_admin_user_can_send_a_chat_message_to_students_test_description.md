# Admin user can send a chat message to students

## Description:

When a user receives a chat message from a user that they could not normally see (e.g. when the admin sends them a message), they will be able to see the name of the sender.

## Step-by-Step Procedure:

1. Using http api endpoint created a class with students and teachers already enrolled and setup.
2. Login as admin.
3. Click on "Messages" tab at bottom
4. Click on "+ Message" button
5. Select a student from student list.
6. Enter message in "Message" tab
7. Click on "Send" icon.
8. Verify the message is visible.
9. Clear the app storage
10. Login to the app using the student username and password.
11. Click on "Messages" tab at bottom 
12. Verify student able to see message from admin as "Admin User"  
13. Click on "Admin User" to open the message 
14. Verify user able to see the message from admin with date and time. 
15. Enter message in "Message" tab to reply 
16. Click on "Send" icon. 
17. Clear the app storage 
18. Login to the app as admin. 
19. Click on "Messages" tab at bottom 
20. Verify admin user able to see reply message from the student.
