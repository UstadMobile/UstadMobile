# When registration is enabled: Users under 13 can register using parental approval link where parent is an existing user

## Description:

When registration is enabled: Users under 13 can register using parental approval link

## Step-by-Step Procedure:

1. Login as admin.
2. Click on "Settings" icon.
3. Click on "Site" button.
4. Click on "Edit" button.
5. Enter Company terms in "Terms and policies" text field.
6. Click on "Registration allowed" switch.
7. Click on "Save" button
8. Clear app storage.
9. Parent user open the app
10. Click on the "New User"
11. Click on the "Learning Space"
12. Click on "Enter link manually"
13. Enter the site link in "Site link" field.
14. Click on the "Next" button
15. Select the date of birth of parent user
16. Click on the "Next" button
17. Read the "Terms and policies"
18. Click on the "Accept" button
19. Enter Full name.
20. Select Gender
21. If platform does not supports passkeys, click on "Other options", then signup with username and password.
22. Enter username and password
23. Click on "Signup" button
24. User logged into the app
25. User directed to courses section
26. Clear app storage.
27. Child user open the app
28. Click on "New User" button
29. Click on "Personal" button
30. Select date of birth , age less than 13 
31. Click on the "Next" button.
32. Enter Full name
33. Select Gender.
34. Enter Parents' email address.
35. Click on Done.
36. Child user gets a page showing "Waiting for parent Consent"
37. Clear the app storage
38. Parent user gets an email asking for parent consent for the child user
39. Parent user clicks on the link in the email.
40. Ustad Mobile app gets open
41. Parent user clicks on "Existing User" button.
42. Click on "Personal" button.
43. User can see list of the child profiles
44. Parent clicks on the child profile (the one who requested permission).
45. Verify Parent able to see child details, "I consent" and "I do not consent" buttons.
46. Parent can edit child details if needed.
47. Parent clicks on "I consent" button.
48. Clicks on "Next" button.
49. User able to see dialogue asking to continue as "Child user" or "Parent user"
50. User clicks "Child user"
51. Child user able to access courses, library features in the app.
